Monitor Google Trends — for free

Track keyword interest over time with zero infrastructure. Daily snapshots, rising/falling detection, and sparklines, all committed to your repo by GitHub Actions.

Fork it on GitHub

✨ What it does

📊 Daily snapshots

Pulls Google Trends interest for your keywords on a schedule and stores each day's values.

📈 Direction detection

Compares the latest value to the previous one and labels each keyword rising, falling, or flat.

✨ Sparklines

Compact Unicode sparklines summarize the trend right in your markdown report.

🌍 Region & language

Configure region and language per keyword to track local interest.

🚀 Quick start

# 1. Fork & clone
git clone https://github.com/pangolinfoapi/google-trends-tracker
cd google-trends-tracker

# 2. Configure keywords
cp keywords.example.json keywords.json
#   edit keywords.json

# 3. Run locally
export PANGOLIN_TOKEN=eyJ...your_jwt
python3 google_trends_tracker.py run
python3 google_trends_tracker.py report

Add the PANGOLIN_TOKEN repository secret and the daily workflow handles the rest.
